# Mission: Teach the LLM Agentic Workflow

## Why
Create a clear 10-15 minute group presentation that explains the workflow behind this agentic environment: what runs the conversation, what teaches the agent behavior, what connects external capabilities, and what preserves knowledge across sessions. The audience should leave able to explain the stack without mixing up harnesses, skills, MCP servers, structural memory, and narrative memory.

## Success looks like
- Present a concise mental model of harnesses vs skills vs MCPs vs memory.
- Use `agentic-env` as the concrete base for install, configuration, and workflow examples.
- Explain why `lean-ctx`, `codebase-memory-mcp`, and `agentmemory` exist, and when each should be used.
- Give a speaker a timed 10-15 minute path, with prompts for audience recall and discussion.

## Constraints
- The lesson must be usable as a group presentation, not only as a private study note.
- The explanation should be descriptive and grounded in trusted docs plus the local `agentic-env` repo.
- Keep the core flow short enough for a live session, with references for follow-up.

## Out of scope
- Deep installation troubleshooting for every supported harness.
- A full MCP protocol implementation tutorial.
- A vendor comparison of all coding agents.
